# Auto Connect 1.1.4 占用优化

2026-10-09，Redmi K80，正式版 1.1.3 → 1.1.4，覆盖安装并保留设置。

## 改动

- release 开启 R8 与资源裁剪，移除未使用的直接预览依赖；保留四个 ABI 和必要的 Manifest 入口。混淆映射保存在构建输出 `app/build/outputs/mapping/release`。
- 应用选择器只枚举包名和名称，按当前组合的可见行异步加载 72×72 图标，使用 applicationContext，无全局位图缓存。
- 主界面使用生命周期感知订阅，Activity 退到后台时停止界面收集，监控服务继续工作。
- 名称缓存最多 64 条；连接失败任务最多持有 50 个命中 id，与历史记录上限一致。
- VPN 状态不变时复用原状态对象，避免无效分配。

## 验证

- release 构建、lintVital 和现有 8 项单元测试通过。
- 实际裁剪后 dex 中仍保留 MainActivity、MonitorService、BootReceiver、WatchdogReceiver 及无参构造。
- 真机权限摘要 6/6，应用选择器图标、列表和包名搜索正常。
- 优化版在前台监控界面退到后台后仍能命中 ChatGPT，FLClash 第一次启动建立 VPN；保留原断开延迟设置。
- 真机退出 ChatGPT：22:50:16.291 检测离开，22:50:24.365 发出第一次停止指令，22:50:26.376 回读 VPN 已断开；之后心跳持续正常。原名单和八秒设置保留。
